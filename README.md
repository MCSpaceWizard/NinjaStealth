# NinjaStealth

A deep-stealth Minecraft mod: darkness and light control (Thief), infiltration tools (Dishonored), social stealth and disguises (Hitman), a broad weapon roster and a hideout with specialised workstations (AC Shadows), all driven by custom stealth AI (perception, suspicion, investigation, search, hunt, patrols, alert propagation).
